## 受入条件

- [x] 通常 query は三欄を全件返し、選択一欄が0件なら `[]`、未選択欄は text / JSON とも省略する。タグと索引済みの階層親を outgoing に含み、独立 tags 欄を出さない。non-note 入口は backlinks を保ち、outgoing / twohop は空。
- [x] `Guide.md` が backlinks と twohop にある場合は各欄に現れる。twohop の `Guide.md` は一件で全 via を持ち、経由ごとの件数制限はない。via X / Y のうち X を除外すれば Y で残り、X を表示から隠せば X 経由の対象は残って X の識別子だけ経由欄から消える。
- [x] `--via` の未登録・型違い・入口が未参照の識別子は twohop を空にし、他 via へ戻らず、直接関係は変えない。指定型が不正・値が空・繰返し指定なら入力エラー。
- [x] `--relations twohop --limit 1` はソート後の有効対象一件を返し、続きがあれば next_offset を返す。offset だけなら末尾まで返す。複数関係と limit / offset の併用、0 以下の limit、負の offset はエラー。total は返さない。
- [x] GLOB の複数指定・config 合成・旧 exclude fallback と明示空上書きが仕様どおり動き、`build.exclude_paths` で索引されなかったリンクや外部 URL は現れない。search の旧 exclude と query 以外の CLI 出力は変わらない。
- [x] inspect は一件の索引済み tags / meta と任意 head を返し、属性選択と head 指定は独立する。query の head は返却 note、snippet は所属関係の edge にのみ対応する。ページ外の対象用プレビューや hidden via に紐づく抜粋は読まず、選択した outgoing の snippet には入口本文を読む。
- [x] `--path` / `--where` は返却対象だけ、`--link-key` は直接 edge だけを絞る。`--link-key` 付きでも本文リンク経由 twohop とその snippet は残る。タグを経由にした入口側のリンク行は tag 入口の backlinks + `--path` で取得できる。
- [x] snippet は 1 始まりの行番号と生の frontmatter 行を返し、重なる別 edge の文脈は別項目とする。本文欠落・索引時からの更新は既存エラーになる。text は path のカンマ・タブ・改行を引用 escape し、JSON は型と選択欄の有無を判別できる。
